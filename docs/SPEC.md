# Walter Knoll 复刻范围 v1

目标：按指定官网风格与十页分工表完成可运行、可维护的英文响应式教学网站。

- A：首页（导航、大图、产品、杂志、关于、订阅）与关于我们（图文、时间轴）。
- B：产品总览（分类筛选、产品卡）与椅子子类（面包屑、分页）。
- C：材料库（九类入口、悬停放大）与皮革详情（大图、描述、色卡）。
- D：杂志（All/News/Stories/References）与专业服务（八项服务、下载）。
- E：可持续（图文、来源明确的统计）与门店联系（门店筛选、联系表单）。

技术：原生 HTML/CSS/JavaScript，CSS 基础→布局→组件→页面四层；公共片段作为导航和页脚的唯一编辑入口，通过脚本生成静态页面，不依赖运行时 fetch 才显示导航。

验收：十页可访问；桌面 1440 与手机 390 无横向溢出；图片正常；页面之间用 `<a>` 互相跳转（图片包在 `<a>` 里），链接只指向这十页；**所有内容写死在 HTML 里**，关掉 JavaScript 也必须能看到产品、文章、材料、门店；筛选栏、分页、Tab、色卡、表单、搜索框只画外观（点击不筛选、不翻页、不提交、不下载）；卡片 hover 有上浮、阴影加深、图片变暗与文字变色。

边界：不开发任何后端、接口、数据库或网络请求，页面脚本中不得出现 `fetch`/`XMLHttpRequest`，不读写 localStorage；不做登录、注册、购物车、收藏、价格变化；不做地图定位（门店卡的地图链接不可点）；下载按钮只保留样式，不提供真实文件。不冒充官方运营，不编造可持续百分比。字体用系统替代。保留旧 runoob-ui-lab，不修改其历史。页面数量固定为十页。

视觉：无动画库与 `@keyframes`，无渐变与毛玻璃，无 3D 与视差；卡片 hover 用 CSS 直接实现上浮 4px、阴影加深、图片 `brightness(.94)` 变暗与标题变色，过渡 `.2s`。选择器只用基础选择器，CSS 变量只有 `:root` 一层。

依据：用户提供的目录说明、wk\_副本.zip、十页截图和 https://www.walterknoll.info/en 。用户明确要求持续开发、GitHub 上传，不增加反复哈希和额外门控。
