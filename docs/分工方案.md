# A–E 分工与维护入口

本文件更新用户压缩包中的分工方案，当前实现与运行方式以 README.md 为准。原始骨架保存在首次 Git 提交中，可随时对照。

| 分工 | 页面           | 专属入口                                                                                  |
| ---- | -------------- | ----------------------------------------------------------------------------------------- |
| A    | 首页、关于     | index.html、pages/about.html、css/pages/index.css、css/pages/about.css、js/pages/index.js |
| B    | 产品、椅子     | pages/products*.html、css/pages/products*.css、js/pages/products.js                       |
| C    | 材料、皮革     | pages/materials*.html、css/pages/materials*.css、js/pages/materials\*.js                  |
| D    | 杂志、专业服务 | pages/magazine.html、pages/professionals.html、对应页面样式、js/pages/magazine.js         |
| E    | 可持续、联系   | pages/sustainability.html、pages/contact.html、对应页面样式、js/pages/contact.js          |

公共导航/页脚：编辑 js/components/header.html、footer.html 后运行 npm run sync:components。
公共变量与断点：css/base.css。公共布局：css/layout.css。复用组件：css/components.css。
页面数据：assets/data/catalog.json，路径相对于项目根目录。新增图片放入相应 assets/images 子目录。

每项修改按用户行为提交，例如“修正产品筛选”或“补充材料纹理”；避免五人同时修改公共片段。提交前运行 npm run check；改变交互或布局时运行 npm test。提交与评审沿用 Git 常规流程，不添加额外门控。

修订点：压缩包称首页有五层但实际只完成前三层，本轮补齐；目前官网顶栏为白底，按实际截图调整；官网返回十个产品分类，保留这十类；可持续数字必须有明确官方依据。
