# Walter Knoll 官网复刻 —— 5 人分工方案

> 目标网站：https://www.walterknoll.info/en
> 要求：响应式界面 · 5 人 · 10 个页面
> 本文件夹 `wk/` 已经是**可运行的项目**：公共导航 + 页脚 + 首页 5 个楼层已按真站复刻完成。

## 一、先搞清楚这个网站长什么样（实测数据，不是编的）

| 项目 | 真站实测值 |
|---|---|
| 技术 | Next.js 服务端渲染（curl 直接能抓到完整 HTML） |
| 一级栏目 | **10 个**：Products / Material Library / Magazine / Designers / Professionals / About us / Sustainability / Retailers / Downloads / Contact |
| 主色 | 纯黑 `#000` + 纯白 `#fff` + 灰阶（极简设计，**没有花哨颜色**） |
| 字体 | 标题衬线（Ivar Display）+ 正文无衬线（Neue Haas Unica Pro），两套都是商业字体，我们用 `Georgia` / `Helvetica Neue` 代替 |
| 响应式断点 | **479px / 859px / 1199px / 1699px** 四档（真站 CSS 里引用次数最多的就是这四个） |
| 内容宽度 | **1352px**（1440 视口下实测；不是固定 max-width，是「满宽减左右各 44px」） |
| 左右留白 | 大屏 62px → 44px → 32px → 手机 20px |
| 顶栏 | 固定(fixed)，桌面 64px 高，手机 48px；首页压在图片上时透明白字，滚动后变白底黑字 |
| 分隔线 | 统一 `1px solid rgba(0,0,0,.16)` |
| 动画 | **几乎没有**（0 个 @keyframes）—— 所以这个站好复刻，不用做复杂动效 |

## 四、统一规范（5 个人必须一致，不然拼不到一起）

### 1. 目录结构
```
wk/  （= project-root）
│
├── index.html                            # [A] 首页（放根目录，方便直接访问）
├── README.md                             # 项目说明（分工 / 启动方式 / 技术栈）
├── .gitignore                            # Git 忽略配置
│
├── pages/                                # 其他 9 个页面
│   ├── about.html               [A]      products.html            [B]
│   ├── products-chairs.html     [B]      materials.html           [C]
│   ├── materials-leathers.html  [C]      magazine.html            [D]
│   ├── professionals.html       [D]      sustainability.html      [E]
│   └── contact.html             [E]
│
├── css/                                  # 四层，别乱放
│   ├── base.css            ← 公共｜变量 + 重置 + 通用排版
│   ├── layout.css          ← 公共｜容器 + 导航 + 页脚 + 响应式断点
│   ├── components.css      ← 公共｜按钮 + 卡片 + 面包屑 + 分页器 + Tab
│   └── pages/              ← 各自｜10 个页面各一个，只写该页独有样式
│
├── js/
│   ├── common.js           ← 公共｜顶栏变色 + 手机菜单 + 导航高亮 + 回到顶部
│   ├── api.js              ← 公共｜数据请求封装 + 本地假数据(MOCK)
│   ├── components/         ← 公共｜header.html + footer.html（导航页脚的源文件）
│   └── pages/              ← 各自｜每页一个，只写该页独有逻辑
│
└── assets/
    ├── images/             ← 按页面分：common/ index/ products/ materials/ magazine/ …
    ├── icons/              ← SVG 图标（箭头、关闭、搜索）
    └── fonts/              ← 字体（本项目用系统字体，空着）
```

> `← 公共` = 要改先在群里说，由组长统一改；`← 各自` = 只有你负责的页面才动
> ⚠️ **`pages/` 里的页面引用资源要加 `../`**：`../css/base.css`、`../assets/images/...`
> 　　写错前缀的话，页面会变成一堆没排版的裸文字

### 2. 每个页面的固定写法
```html
<!-- pages/ 里的页面记得每行都加 ../ 前缀 -->
<link rel="stylesheet" href="../css/base.css">
<link rel="stylesheet" href="../css/layout.css">
<link rel="stylesheet" href="../css/components.css">
<link rel="stylesheet" href="../css/pages/你的页面.css">
...
<script src="../js/api.js"></script>          <!-- 数据封装 -->
<script src="../js/common.js"></script>       <!-- 公共逻辑 -->
<script src="../js/pages/你的页面.js"></script> <!-- 本页逻辑 -->
```
> 顺序不能乱：**基础 → 布局 → 组件 → 页面**（后面的覆盖前面的）。

### 3. 从骨架复制什么？
- **复制**：`<header class="site-header">` 整块 + `<div class="drawer">` 整块 + `<footer class="site-footer">` 整块
  （也可以直接从 `components/navbar.html` 和 `components/footer.html` 里复制）
- **不要复制**：`class="on-hero"`（这个只有首页才有，因为首页顶上是大图）
- **只改**：`<main>` 里面的内容

### 4. 改动公共部分的规则
> **要改导航或页脚 → 先在群里说一声 → 由 A 改 `js/components/` 里的源文件，再同步到全部 10 个页面**
> 谁都不能自己偷偷改，否则别人的页面全对不上。

### 5. 配色和字体（都写在 `css/base.css` 顶部的变量里）
```css
--black: #000000;      /* 主色 */
--white: #ffffff;
--gray-300: #d9d9d9;
--gray-100: #f5f5f5;   /* 浅灰底块 */
--line: rgba(0,0,0,.16);  /* 所有细线 */
```
> 想换颜色只改这几个变量，**不要在别处写死颜色**。

### 6. 断点写法（统一用这 4 档）
```css
@media (max-width: 1199px) { }   /* 小笔记本 */
@media (max-width: 859px)  { }   /* 平板 */
@media (max-width: 479px)  { }   /* 手机 */
@media (min-width: 1700px) { }   /* 大屏 */
```

## 八、注意事项

1. **图片版权**：素材来自原站，**仅供课程练习，不要发布到网上、不要商用**。报告里注明"素材来源于原站，用于教学演示"。
2. **不用框架**：这次作业只用 HTML + CSS + 原生 JS，别引入 Bootstrap / Vue（老师要看手写能力）。
3. **JS 越少越好**：这个站本身没什么动效，只需要 `js/script.js` 里那两个功能（顶栏变色 + 手机菜单）。
4. **字体**：真站用的商业字体拿不到，统一用 `Helvetica Neue` 代替，**别每个人都去试不同的字体**。
5. **英文站**：真站是英文的，我们的复刻也保持英文，跟原站一致。
